# Abhiraj Yadav Portfolio — Frontend

Modern responsive portfolio built with **React, Vite, Tailwind CSS, Framer Motion and Lucide Icons**.

## Run

```bash
npm install
cp .env.example .env
npm run dev
```

Open `http://localhost:5173`.

### Backend connection
- Local: leave `VITE_API_URL` empty (Vite automatically proxies `/api` to `http://localhost:5001`).
- Production: set `VITE_API_URL=https://your-backend-domain.com` before `npm run build`.

## Build

```bash
npm run build
npm run preview
```
